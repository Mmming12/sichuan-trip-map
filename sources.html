两个版本均读取本站保存的 amap-data.js，不重新请求路线规划。原版浏览器不使用高德 API；高德版浏览器使用 JS API Key 加载高德地图，地图初始化会计量。JS API Key 是浏览器端标识，可被访客看到；配套安全密钥由 Vercel 代理在服务端注入，Web 服务 Key 继续只留在作者本机。点“在高德重新查路线”才会打开高德网站或 App；地图底图仍需联网加载。作者在本机刷新数据时会使用本机配置的 Web 服务 Key 和相应用量。高德版切换日期和查看保存路线只更新图钉／折线，共用一个地图实例；没有实时搜索和算路功能。
